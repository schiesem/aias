# Figures of the dissertation

These are the figures of the dissertation this version publishes, carried here
so that the drawing and the ontology sit together.

| File | What it shows |
|---|---|
| `figures-aias-alignment.pdf` | The alignment: the three collecting classes, what each pattern contributes to them, and the seven kinds of device below the resource. |

They are drawn by hand rather than rendered from a source, so they are
versioned in the repository. Everything in a `figures/` directory of a 2.0.0 is
generated from a `.puml` and is not.

**The figure is the binding source where it differs from the OWL file of the
dissertation.** `CHANGES.md` of this version records each such difference and
which one was followed.
