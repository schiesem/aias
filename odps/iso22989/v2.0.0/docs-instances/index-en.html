ISO/IEC 22989 Pattern: Named Individuals: Description back to ToC

Every individual here carries the clause of ISO/IEC 22989:2022 that defines it. The pattern records that a value belongs to a quality, not how the quality is measured. Robustness as a number between zero and one is one convention among several, and prescribing a scale here would put a measurement decision into a terminology pattern. A model states the scale it uses through the unit of the value, or through an annotation on it.
