Abstract

An ontology design pattern for describing the communication between the components of an automated plant, following the layered architecture of ISO/IEC 7498-1, the Basic Reference Model of Open Systems Interconnection. A communication is structured into the seven layers of the reference model, each layer is realised by a technology such as Ethernet, IP or MQTT, and the content carried is a data unit assigned either to a layer or to the communication itself. The layers, the technologies and the kinds of data unit are modelled as subclasses. The pattern is one of three subdomain patterns of the AIAS information model and is meant to be imported and aligned rather than used on its own.
