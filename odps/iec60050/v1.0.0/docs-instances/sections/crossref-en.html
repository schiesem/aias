Control Rise Timeni back to ToC or Named Individual ToC

IRI: https://w3id.org/aias/odp/iec60050/instances#ControlRiseTime

The interval after a step change of the reference variable or a disturbance variable, beginning when the controlled variable first leaves an agreed tolerance band around its desired value and ending when it first returns into that band.
belongs to
Time Characteristic c
has facts
symbol dp "T_cr"
note ap "IEC 60050-351, 351-46-01. English wording reconstructed from the German entry. It ends at the first return, whereas the control settling time requires the controlled variable to stay inside."@en
