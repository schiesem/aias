# Versions of the IEC 60050-351 ontology

Every version is a directory of its own and a maintained branch, not a frozen
copy. A version may still receive a patch release after a newer one exists.

| Version | Standing | Directory |
|---|---|---|
| **1.0.0** | current | `v1.0.0/` |

**Current is 1.0.0.** An IRI without a version resolves to it; a versioned
IRI such as `.../1.0.0` resolves to that version and keeps doing so once a
newer one is published.

There is no earlier version. This pattern has no counterpart in the
dissertation and is a first release.
